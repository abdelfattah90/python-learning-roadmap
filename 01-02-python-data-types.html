01الشرح

النصوص والأعداد: str و int و float و complex

هذه هي القيم "المفردة" التي يخزّنها البرنامج في المتغيرات. int للأعداد الصحيحة (كميات، عدّادات) ولا حد أقصى عمليًا لحجمها. float للأعداد العشرية (أسعار، درجات حرارة)؛ أهم قيد فيه أن 0.1 + 0.2 لا يساوي تمامًا 0.3 بسبب التمثيل الثنائي، لذلك لا تقارن أموالًا بـ float مباشرة. str سلسلة محارف غير قابلة للتعديل بعد إنشائها. complex عدد له جزء حقيقي وجزء خيالي يُكتب بـ j، ويُستخدم في الهندسة الكهربائية والإشارات أكثر من البرمجة اليومية.

التجميعات المتسلسلة: list و tuple و range

كلها تحفظ عناصر مرتبة يمكن الوصول إليها بالفهرسة. list قابلة للتعديل بعد إنشائها (إضافة وحذف وتغيير)، وهي الخيار الافتراضي للمجموعات المتغيرة؛ خطؤها الشائع أن نسخها المتغيرة (مثل b = a) تبقى مرتبطة بالأصل. tuple ثابتة، فتصلح لسجلّات ذات حقول معروفة مثل إحداثيات أو إعدادات لا يجوز تغييرها؛ انتبه أن tuple ذات عنصر واحد تحتاج فاصلة: (5,) وليست (5). range تسلسل أرقام صحيحة "كسول" لا يخزّن كل الأرقام دفعة واحدة، مثالي للتكرار عددًا من المرات.

الخرائط والمجموعات: dict و set و frozenset

dict تربط كل قيمة بمفتاح فريد، والبحث بالمفتاح سريع مهما كبرت الخريطة؛ أهم خطأ فيها هو الوصول بمفتاح غير موجود فيرفع KeyError. set مجموعة غير مرتبة تحفظ كل قيمة مرة واحدة فقط، لذا هي الأداة الطبيعية لإزالة التكرار وفحص العضوية، لكنها لا تدعم الفهرسة. frozenset نسخة ثابتة من set لا تقبل الإضافة ولا الحذف، وتكمن فائدتها في أنها نفسها يمكن أن تكون مفتاحًا في dict لأنها immutable.

البيانات الثنائية: bytes و bytearray و memoryview

هذه الأنواع تتعامل مع البيانات الخام على هيئة أرقام من 0 إلى 255، وتظهر عند قراءة الملفات والتعامل مع الشبكات. bytes ثابتة بعد إنشائها ويُكتب قيمها بحرف b قبل النص. bytearray نفس الفكرة لكنها قابلة للتعديل بايتًا بايت. memoryview نافذة على ذاكرة كائن بايتات دون نسخها، فهي أداة كفاءة للبيانات الكبيرة؛ الأمر المهم أن تعديلها يعدّل الكائن الأصلي مباشرة.

القيم الخاصة والفحص: bool و NoneType و type()

bool له قيمتان فقط True و False ويكون ناتج المقارنات والشروط؛ لطيفة أن bool فرع من int في Python فيعمل True + True ويساوي 2. NoneType نوع قيمته الوحيدة None ومعناها "لا قيمة هنا عمدًا"، فتُستخدم للمتغيرات غير المهيأة أو الحقول الناقصة، وتُقارن دائمًا بـ is None. أما type(x) فتعيد نوع أي قيمة، وهي أول أداة تلجأ إليها عندما لا تتصرف البيانات كما توقعت.

02الملخص

  • int للأعداد الصحيحة و float للعشرية (انتبه لتقريب الأرقام مثل 0.1 + 0.2) و complex للأعداد بجزء خيالي، و str للنصوص غير القابلة للتعديل.
  • list مرتبة وقابلة للتعديل، tuple مرتبة وثابتة، و range تسلسل أرقام كسول لا يخزّن كل قيمه.
  • dict تبحث بالمفتاح بسرعة لكن الوصول بمفتاح غير موجود يرفع KeyError، و set تحفظ القيم الفريدة فقط دون ترتيب أو فهرسة، و frozenset نسخة ثابتة منها.
  • bytes ثابتة و bytearray قابلة للتعديل و memoryview نافذة على ذاكرة الأصل بلا نسخ، وتعديلها يغيّر الأصل.
  • None تعني "لا قيمة" وتُقارن بـ is None، و bool فرع من int فـ True + True يساوي 2.
  • type(x) تعيد نوع أي قيمة وهي أول أدواتك لفهم سلوك البيانات وتصحيح الأخطاء.

03أسئلة المقابلات

ما الفرق بين list و tuple؟ ومتى تختار كلًا منهما؟أساسي

كلاهما تجميعة مرتبة قابلة للفهرسة، لكن list قابلة للتعديل بينما tuple ثابتة بعد الإنشاء. اختر list للبيانات المتغيرة كقائمة المهام، واختر tuple للسجلات الثابتة كالإحداثيات أو إعدادات لا يجوز تغييرها.

تابع: الثبات يجعل tuple مفتاحًا صالحًا داخل dict على عكس list.

ما الفرق بين set و list؟أساسي

list ترتيب العناصر وتحفظ التكرار وتدعم الفهرسة، أما set فتحفظ كل قيمة مرة واحدة فقط ولا تضمن ترتيبًا ولا تدعم الفهرسة. استخدم set لإزالة التكرار وفحص العضوية السريع، وlist عندما يهمك الترتيب أو تكرار العناصر.

ما الفرق بين None والقيم الفارغة "" أو 0 أو []؟متوسط

None تعني "لا قيمة أصلًا" بينما "" نص فارغ موجود و 0 عدد صالح و [] قائمة فارغة؛ كلها كائنات حقيقية ذات نوع. لذلك تُقارن None بـ is None لا بـ == ""، لأن الحقل الفارغ في البيانات الحقيقية معناه مختلف تمامًا عن الحقل المفقود.

ما الفرق بين bytes و bytearray و memoryview؟متوسط

bytes تسلسل بايتات ثابت لا يمكن تعديله، و bytearray نفس البنية لكنها قابلة للتعديل، و memoryview نافذة على ذاكرة أحدهما دون نسخ البيانات. تُستخدم الثلاثة مع الملفات والشبكات، و memoryview تحديدًا عند الحاجة لكفاءة مع بيانات كبيرة، مع انتباه أن تعديلها يغيّر الكائن الأصلي.

هل True + True صالح في Python؟ وما ناتجه؟فخ

نعم صالح وناتجه 2، لأن bool في Python فرع من int حيث True == 1 و False == 0. الفخ أن من يفترض أن bool نوع مستقل منفصل عن الأرقام سيفاجأ بسلوك مثل True + True أو استخدام True كعدّاد.

تابع: لهذا السبب تجنب استخدام == True واكتب الشرط المباشر بدلًا منه.

  4. تفسير القرارات: اخترنا dict لكل سجل لأن حقوله معنونة بالأسماء لا بالمواضع، واخترنا set للعملاء لأن التكرار لا يهمنا والعضوية فيه فحص سريع. استخدمنا is None لأنه الفحص الصحيح لقيمة None، واستخدمنا continue لنتخطى السجل الناقص دون تشويش على الجمع.

01الشرح

تعريف الدالة واستدعاؤها — Define & Call Functions

لماذا؟ عندما يتكرر المنطق نفسه (طباعة فاصل، حساب ضريبة، تنسيق رسالة) نكتبه مرة واحدة تحت اسم واضح ثم نعيد استخدامه. هذا يقلل التكرار، ويجعل التعديل في مكان واحد، ويسهّل الاختبار.

Define Functions: نعرّف الدالة بالكلمة def ثم اسم الدالة (بنمط snake_case وبفعل معبّر مثل calculate_total) ثم الأقواس والنقطتين :، وبعدها الجسم (body) بمسافة بادئة موحدة من 4 مسافات. التعريف وحده لا ينفّذ الجسم؛ هو فقط ينشئ الدالة ويربطها بالاسم.

Call Functions: نستدعي الدالة باسمها متبوعًا بأقواس: print_separator(). الأقواس هي التي تنفّذ الجسم، أما كتابة الاسم وحده فتشير إلى كائن الدالة دون تشغيله. ويجب أن يسبق التعريف أول استدعاء فعلي، وإلا ظهر NameError. ويمكن استدعاء الدالة نفسها أي عدد من المرات.

الخطأ الشائع: نسيان الأقواس عند الاستدعاء. لا يظهر خطأ، لكن لا يحدث شيء، وهذا يصعّب اكتشافه.

Function Arguments و Positional Arguments

لماذا؟ الدالة التي تعمل بقيم ثابتة فائدتها محدودة. نريد تمرير بيانات مختلفة في كل استدعاء لتعمل الدالة نفسها على حالات متعددة.

Function Arguments: الـ parameter هو الاسم الذي نكتبه بين الأقواس عند التعريف (مثل item)، والـ argument هو القيمة الفعلية التي نمررها عند الاستدعاء (مثل "Notebook"). الـ parameters تعمل كمتغيرات داخل جسم الدالة.

Positional Arguments: أبسط طريقة للتمرير: تُربط الـ arguments بالـ parameters حسب الموضع، الأول بالأول والثاني بالثاني. ويجب أن يطابق عدد الـ arguments عدد الـ parameters، وإلا يرفع Python الخطأ TypeError.

القيد الأهم: إذا بدّلت الترتيب وكانت القيم صالحة للعمليات داخل الدالة، فلن يظهر خطأ بل نتيجة خاطئة بصمت. لذلك اختر أسماء parameters واضحة وراجع الترتيب عند الاستدعاء. (توجد طرق أخرى لتمرير arguments ستأتي في دروس لاحقة.)

Return Values — إرجاع القيم

لماذا؟ كثيرًا ما نريد أن تحسب الدالة قيمة وتسلّمها لمن استدعاها ليخزّنها أو يجري عليها عمليات أو يمررها لدالة أخرى، بدل أن تكتفي بعرضها على الشاشة.

كيف يعمل؟ return يرسل قيمة إلى مكان الاستدعاء ويُنهي الدالة فورًا، فأي سطر بعده في المسار نفسه لا يُنفَّذ. ويمكن استخدامه مبكرًا داخل if للخروج من الدالة عند حالة خاصة.

إذا لم توجد return فإن الدالة تعيد None. ومن هنا الفرق بين print وreturn: الأولى تعرض نصًا فقط، والثانية تعطيك قيمة قابلة للاستخدام.

لإرجاع أكثر من قيمة اكتبها مفصولة بفواصل: return first, last. تُرجع Python عندها tuple واحدًا، ويمكن فكّه مباشرة (unpacking) إلى متغيرات.

الخطأ الشائع: استخدام print داخل الدالة ثم محاولة استخدام نتيجتها، فتحصل على None.

02الملخص

  • def name(parameters): مع مسافة بادئة تعرّف دالة، والتعريف وحده لا ينفّذ الجسم.
  • الاستدعاء يحتاج أقواسًا name()؛ بدونها تشير إلى الدالة ولا تشغّلها، ويجب أن يسبق التعريف الاستدعاء.
  • الـ parameter هو الاسم في التعريف، والـ argument هو القيمة التي تمررها عند الاستدعاء.
  • الـ positional arguments تُربط بالترتيب؛ العدد الخاطئ يعطي TypeError، والترتيب الخاطئ قد يمر بصمت.
  • return يعيد قيمة وينهي الدالة؛ وبدونه تعيد الدالة None، وprint لا يغني عنه.
  • return a, b يعيد tuple يمكن فكّه بـ unpacking؛ ويفضّل أن تؤدي كل دالة مهمة واحدة باسم فعلي واضح.

03أسئلة المقابلات

ما الفرق بين parameter و argument؟أساسي

الـ parameter هو الاسم المعرَّف في توقيع الدالة ويعمل كمتغير داخلها، أما الـ argument فهو القيمة الفعلية التي تُمرَّر عند الاستدعاء. في def f(x) وf(5) يكون x هو parameter والقيمة 5 هي argument.

متابعة: ماذا لو مرّرت argument زائدًا؟ يرفع Python الخطأ TypeError لأن العدد لا يطابق.

ما الفرق بين print وreturn داخل الدالة؟أساسي

print تعرض القيمة على الشاشة فقط ولا تعطي المستدعي شيئًا، فتعيد الدالة None. أما return فترسل القيمة إلى مكان الاستدعاء لتُخزَّن أو تُستخدم في حسابات أخرى، وتُنهي تنفيذ الدالة.

ماذا يحدث عند تمرير positional arguments بعدد أو ترتيب خاطئ؟متوسط

العدد الخاطئ يرفع TypeError برسالة مثل missing 1 required positional argument. أما الترتيب الخاطئ فلا يرفع خطأً إن كانت القيم صالحة للعمليات داخل الدالة، فتحصل على نتيجة خاطئة بصمت. لذلك تهم أسماء الـ parameters الواضحة واختبار الدالة بقيم معروفة.

كيف تُرجع الدالة أكثر من قيمة؟ وماذا تُرجع فعليًا؟متوسط

تكتب القيم مفصولة بفواصل: return first, last. الفاصلة هي التي تصنع tuple، فتعيد الدالة كائنًا واحدًا. يستقبله المستدعي كما هو أو يفكّه بـ unpacking: first, last = split_name(...)، ويجب أن يطابق عدد المتغيرات عدد القيم وإلا ظهر ValueError.

ما الذي يطبعه الكود التالي ولماذا؟فخ

يبدو أن new_price سيحمل السعر بعد الضريبة، لكن الدالة تستخدم print ولا تستخدم return.

يطبع 114.0 من داخل الدالة، ثم None لأن الدالة لم ترجع شيئًا. الحل أن نستبدل print(total) بـ return total.

    المدخلات: item وunit_price وquantity وtax_percent. المخرجات: ثلاث قيم (اسم البند، الإجمالي قبل الضريبة، الإجمالي بعدها). نحتاج دوالًا تعيد قيمًا لأن نتيجة دالة تدخل في حساب دالة أخرى.

    دالتان صغيرتان لكل منهما مهمة واحدة (calculate_line_total وadd_tax)، ثم summarize_order تستدعيهما وتعيد النتائج. الطباعة تتم خارج الدوال.

  4. تفسير القرارات

    استخدمنا return لا print حتى تُستخدم النتائج في خطوات أخرى. وفصلنا الدوال لتُختبر وتُعاد كل واحدة على حدة. وترتيب الاستدعاء ("Coffee", 40, 3, 14) يطابق ترتيب الـ parameters تمامًا. وأعدنا tuple فكّكناه مباشرة في ثلاثة متغيرات.

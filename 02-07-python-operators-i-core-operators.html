01الشرح

1. Arithmetic Operators و Assignment Operators

نستخدم Arithmetic Operators لإجراء الحسابات داخل البرنامج: الجمع +، الطرح -، الضرب *، القسمة /، القسمة الصحيحة //، باقي القسمة %، والأس **. تعيد / نتيجة قسمة عادية، بينما // تقرّب الناتج إلى الأسفل؛ لذلك قد تكون نتيجة القسمة الصحيحة مع الأعداد السالبة مختلفة عما تتوقعه إذا فكرت في حذف الجزء العشري فقط. تُستخدم % كثيرًا للتحقق من الزوجية أو تقسيم العناصر إلى مجموعات.

تحدد أولوية العمليات ترتيب التنفيذ؛ فالأقواس () توضح الترتيب المقصود وتقلل الالتباس. أما Assignment Operators فتسند قيمة إلى متغير باستخدام =، أو تحدّث قيمته باختصار مثل += و-= و*= و/= و//= و%= و**=. استخدم الصيغة المختصرة عندما تكون العملية تحديثًا للمتغير نفسه؛ وانتبه إلى أن = للإسناد وليس للمقارنة.

2. Comparison Operators

تجيب Comparison Operators عن أسئلة المقارنة وتنتج قيمة Boolean هي True أو False. تشمل المساواة ==، وعدم المساواة !=، والأكبر >، والأصغر <، والأكبر أو يساوي >=، والأصغر أو يساوي <=. نستخدمها للتحقق من شروط مثل بلوغ حد أدنى للسعر أو مطابقة كلمة مرور تجريبية.

يمكن ربط المقارنات مثل 18 <= age < 65 بدل كتابة شرطين منفصلين. لا تخلط بين == التي تقارن القيم و= التي تسند قيمة؛ كما أن مقارنة أنواع غير متوافقة، مثل عدد ونص باستخدام <، قد تؤدي إلى TypeError.

3. Logical Operators

تجمع Logical Operators نتائج الشروط لتكوين قرار واحد: and تكون صحيحة عندما يكون الشرطان صحيحين، وor تكون صحيحة إذا تحقق شرط واحد على الأقل، وnot تعكس قيمة الشرط. نستخدمها مثلًا للسماح بخصم عند تحقق شرطين، أو قبول الطلب إذا تحقق أحد مسارين.

تتوقف Python عن تقييم بقية التعبير متى أصبحت النتيجة محسومة؛ وهذا يسمى short-circuit evaluation. لذلك يمكن وضع فحص آمن أولًا قبل عملية قد لا تصلح في كل الحالات. تذكّر أولوية not ثم and ثم or، واستخدم الأقواس عندما تريد توضيح تجميع الشروط.

4. Ternary Operator (Conditional Expression)

يسمح Ternary Operator باختيار واحدة من قيمتين بناءً على شرط في تعبير واحد، وصيغته: value_if_true if condition else value_if_false. يفيد عندما يكون الاختيار بسيطًا، مثل تحديد رسالة حالة أو قيمة افتراضية قصيرة. وهو تعبير يعيد قيمة يمكن إسنادها إلى متغير أو استخدامها داخل تعبير آخر.

إذا احتجت إلى عدة فروع أو منطق طويل، فاستخدم if/elif/else بدل تكديس تعبيرات شرطية متداخلة؛ فالإيجاز لا ينبغي أن يقلل وضوح الكود.

02الملخص

  • المعاملات الحسابية تشمل + و- و* و/ و// و% و**؛ ولكل منها سلوك مختلف.
  • الأقواس توضح أولوية الحساب، و// تقرّب الناتج إلى الأسفل لا نحو الصفر.
  • = للإسناد، بينما معاملات مثل += و*= تحدّث قيمة المتغير.
  • معاملات المقارنة تنتج True أو False، ويمكن ربط المقارنات المتتابعة.
  • and وor وnot تجمع الشروط، وتستخدم Python التقييم المختصر.
  • التعبير الشرطي المختصر يختار قيمة بين بديلين؛ اجعل استخدامه بسيطًا وواضحًا.

03أسئلة المقابلات

ما الفرق بين / و// في Python؟أساسي

المعامل / ينفذ قسمة عادية ويعيد عادةً قيمة من النوع float. أما // فينفذ قسمة صحيحة ويقرّب الناتج إلى الأسفل، وليس بمجرد حذف الجزء العشري.

ما الفرق بين = و==؟أساسي

= تسند قيمة إلى متغير، بينما == تقارن قيمتين وتنتج True أو False. استخدام = داخل شرط مقارنة بدل == خطأ شائع.

كيف تعمل معاملات and وor معًا، وما فائدة الأقواس؟متوسط

لـ and أولوية أعلى من or، لذلك تُقيّم مجموعة and قبل or. الأقواس تجعل التجميع المقصود ظاهرًا وتمنع سوء فهم الشروط المركبة.

ما المقصود بـ short-circuit evaluation؟متوسط

تتوقف Python عن تقييم التعبير عندما تصبح النتيجة معروفة دون الحاجة إلى بقية الشروط. مثلًا في condition and another_check لن يُقيّم الطرف الثاني إذا كان الأول غير صحيح، ويمكن الاستفادة من ذلك لتجنب فحص غير آمن.

ما ناتج print(-7 // 3, -7 % 3)؟ ولماذا؟سؤال فخ

الناتج هو -3 2. لأن // تقرّب إلى الأسفل، ونتيجة القسمة تحقق العلاقة a == (a // b) * b + (a % b)؛ لذلك لا يكون باقي القسمة هنا سالبًا.

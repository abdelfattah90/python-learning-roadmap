01الشرح

Create Files وwrite() وw Mode: إنشاء الملف والكتابة فيه

لماذا؟ متغيرات البرنامج تختفي عند انتهائه، أما الملف فيحفظ النتائج (تقارير، logs، إعدادات) بعد انتهاء التشغيل.

Create Files: لا توجد دالة مستقلة للإنشاء؛ يُنشأ الملف عبر open(path, mode) بأحد ثلاثة أوضاع: "w" ينشئ الملف أو يفرغه إن وُجد، و"a" ينشئه أو يضيف إليه، و"x" ينشئه فقط ويرفع FileExistsError إن وُجد، وهو الأكثر أمانًا حين لا تريد الكتابة فوق ملف قائم.

write(): تقبل str فقط (تمرير رقم يرفع TypeError)، وتُرجع عدد الأحرف المكتوبة، ولا تضيف سطرًا جديدًا تلقائيًا، فأضف \n بنفسك. استخدم with ليُغلق الملف ويُحفظ المحتوى تلقائيًا، وحدّد encoding="utf-8" لأن الافتراضي يختلف بين الأنظمة.

w Mode: يمسح المحتوى القديم لحظة فتح الملف، حتى لو لم تكتب شيئًا. أخطر خطأ هنا فتح ملف مهم بـ "w" وأنت تريد قراءته أو الإضافة إليه.

a Mode: الإضافة دون مسح

لماذا؟ في سجلات الأحداث (logs) تريد تراكم السطور لا استبدالها. الوضع "a" يضع المؤشر في نهاية الملف، فيُضاف كل write() بعد المحتوى الحالي، ويُنشأ الملف إن لم يوجد.

القيد: لا يُضاف فاصل سطر قبل أول كتابة، فإن انتهى الملف الموجود دون \n التصق السطر الجديد به. وكل تشغيل للبرنامج يضيف من جديد: بعد التشغيل الأول يحتوي app.log سطرين، وبعد الثاني أربعة.

Delete Files وos Module: حذف الملفات

لماذا؟ لتنظيف الملفات المؤقتة والقديمة. الملف المفتوح بـ open() لا يحذف نفسه؛ الحذف عملية نظام تشغيل تقدمها الوحدة os التي تستوردها بـ import os كما في درس Modules.

os.remove(path) يحذف ملفًا واحدًا نهائيًا دون سلة محذوفات. يرفع FileNotFoundError إن لم يوجد الملف، وPermissionError إن لم تملك الصلاحية. أغلق الملف قبل حذفه (على Windows لا يُحذف ملف مفتوح)، ولحذف مجلد فارغ استخدم os.rmdir().

Check File Existence: التحقق من وجود الملف

لماذا؟ لاتخاذ قرار منطقي، مثل عدم إنشاء ملف الإعدادات إن كان موجودًا. os.path.exists(path) تُرجع True إن وُجد المسار سواء كان ملفًا أو مجلدًا، وos.path.isfile(path) تُرجع True للملف العادي فقط، وهي الأدق قبل الحذف.

القيد: الفحص لا يضمن بقاء الملف حتى لحظة التنفيذ (قد يحذفه برنامج آخر بين السطرين). لذلك استخدم if للقرارات المنطقية، وtry/except FileNotFoundError عند الحذف أو القراءة الحرجة.

02الملخص

  • الأوضاع "w" و"a" و"x" تنشئ الملف؛ "x" وحده يرفض الكتابة فوق ملف موجود.
  • write() تقبل str فقط، وتُرجع عدد الأحرف، ولا تضيف \n تلقائيًا.
  • "w" يمسح المحتوى القديم فور الفتح، و"a" يضيف في النهاية دون مسح.
  • استخدم with وencoding="utf-8" لإغلاق الملف تلقائيًا وتفادي مشكلات الترميز.
  • os.remove(path) يحذف ملفًا نهائيًا ويرفع FileNotFoundError إن غاب؛ وos.rmdir() للمجلد الفارغ.
  • os.path.exists للملف أو المجلد، وos.path.isfile للملف فقط، والفحص المسبق لا يغني عن try/except في العمليات الحرجة.

03أسئلة المقابلات

ما الفرق بين الوضعين w وa؟أساسي

"w" يمسح محتوى الملف الموجود عند فتحه ثم يكتب من البداية، و"a" يُبقي المحتوى ويكتب بعد آخره. كلاهما ينشئ الملف إن لم يوجد.

متابعة: متى أستخدم كلًّا منهما؟ "w" لتقرير يُعاد توليده كل مرة، و"a" للـ logs المتراكمة.

ماذا تُرجع write() وماذا يحدث إن مرّرت لها رقمًا؟أساسي

تُرجع عدد الأحرف المكتوبة. وهي تقبل str فقط، فتمرير 42 يرفع TypeError؛ حوّله أولًا بـ str() أو f-string. ولا تضيف \n تلقائيًا.

كيف تنشئ ملفًا جديدًا مع منع الكتابة فوق ملف موجود؟متوسط

افتحه بالوضع "x"؛ إن كان الملف موجودًا يُرفع FileExistsError فتعالجه بـ try/except. هذا أأمن من فحص os.path.isfile ثم "w" لأن الفحص والإنشاء يتمان في خطوة واحدة.

هل أفحص بـ os.path.exists قبل os.remove أم أستخدم try/except؟متوسط

الأفضل غالبًا try/except FileNotFoundError؛ لأن الملف قد يُحذف بين الفحص والحذف فيفشل الكود رغم نجاح الفحص. الفحص المسبق مناسب حين تحتاج قرارًا منطقيًا مختلفًا، لا حماية من الخطأ.

ماذا يحدث عند تنفيذ with open("customers.txt", "w") as f: data = f.read()؟فخ

فتح الملف بـ "w" يفرغه فورًا قبل أي قراءة، ثم يفشل read() بـ io.UnsupportedOperation لأن الملف غير قابل للقراءة. النتيجة: ضاعت البيانات ولم تقرأ شيئًا. استخدم "r" للقراءة و"a" للإضافة.

    المدخل قائمة مبيعات (اسم وسعر). المطلوب ملف يبدأ بعنوان ثم ثلاثة أسطر، وطباعة المحتوى ومجموع الأحرف المضافة، ثم حذف الملف بأمان.

  2. خطة الحل

    فحص os.path.isfile وإنشاء الملف بـ "w" مع العنوان إن غاب، ثم فتحه بـ "a" وجمع القيم المُرجعة من write()، ثم قراءته وطباعته، ثم os.remove داخل try/except.

  3. الكود الكامل

  4. تفسير القرارات

    نستخدم "w" للعنوان فقط وعند غياب الملف حتى لا نمسح بيانات موجودة، و"a" للعمليات لأنها تتراكم. جمع قيمة write() يعطي عدد الأحرف دون إعادة قراءة الملف. والحذف داخل try/except لأن الفحص المسبق لا يضمن بقاء الملف.

  5. اختبار سريع

    شغّل البرنامج مرتين متتاليتين؛ يجب أن يتكرر الناتج نفسه لأن الملف يُحذف في النهاية. ولإثبات الحذف أضف في آخره print(os.path.exists(LOG_FILE)) فتظهر False.

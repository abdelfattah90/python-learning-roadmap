01الشرح

1. Boolean Values وTrue وFalse

نحتاج القيم المنطقية لتمثيل حالة لها احتمالان، مثل كون الحساب نشطًا أو غير نشط، أو اكتمال الدفع أو عدم اكتماله. نوعها في Python هو bool، وله قيمتان فقط: True وتعني صحيح، وFalse وتعني خطأ.

True وFalse ثوابت جاهزة في اللغة، ويجب كتابة الحرف الأول كبيرًا كما هو موضح؛ فـ true وfalse ليستا الصياغة الصحيحة في Python. كذلك فهما قيمتان منطقيتان وليستا نصين، لذلك لا نضعهما بين علامات اقتباس.

2. Boolean Expressions

Boolean Expression هو تعبير تُقيَّم نتيجته إلى قيمة منطقية. غالبًا نبنيه بمقارنة قيم باستخدام == و!= و> و< و>= و<=، ثم نربط الشروط باستخدام and أو or أو نعكس النتيجة باستخدام not.

نستخدم هذه التعبيرات للإجابة عن أسئلة عملية مثل: هل العمر مناسب؟ وهل يوجد حجز؟ في المثال، لا يصبح السماح بالدخول صحيحًا إلا إذا تحقق الشرطان معًا. عندما تكون أطراف and أو or مقارنات منطقية تكون النتيجة bool؛ لكن هذين العاملين قد يعيدان أحد القيمتين الأصليتين في تعبيرات أخرى، بينما not يعيد دائمًا قيمة منطقية.

3. الدالة bool()

تُستخدم bool() لتحويل قيمة إلى نتيجة منطقية وفق ما إذا كانت القيمة تُعدّ «فارغة أو صفرية» أم لا. مثلًا، العدد 0 والنص الفارغ "" يعطيان False، بينما العدد غير الصفري والنص غير الفارغ يعطيان True.

يفيد ذلك عند فحص وجود قيمة أو كونها ذات محتوى، لكن لا تخلط بين حقيقة النص ومعناه: bool("False") نتيجتها True لأن النص نفسه غير فارغ؛ فالدالة لا تفسّر الكلمة المكتوبة داخله.

4. None وNone vs. False وNone vs. 0

None قيمة خاصة تعبّر عن عدم وجود قيمة حاليًا، مثل حقل لم يُحدَّد بعد. نوعها هو NoneType، ولفحصها نستخدم عادةً is None أو is not None؛ فهذا أوضح من مقارنتها باستخدام ==.

لا تعني None الشيء نفسه الذي تعنيه False أو 0: الأولى تعني أن القيمة غير موجودة أو لم تُحدَّد، والثانية تعني إجابة منطقية سلبية صريحة، أما الصفر فهو قيمة عددية حقيقية. صحيح أن bool(None) وbool(False) وbool(0) كلها تعطي False، لكن هذا لا يجعل القيم متساوية؛ فكل من None == False وNone == 0 نتيجته False. تنبيه: في Python تكون False == 0 صحيحة، رغم اختلاف نوعيهما.

02الملخص

  • القيم المنطقية من النوع bool، ولا توجد له إلا True وFalse.
  • اكتب True وFalse بحالة الأحرف الصحيحة، ومن دون علامات اقتباس.
  • ينتج Boolean Expression قيمة منطقية غالبًا عبر المقارنة، ويمكن تركيب الشروط بـ and وor وnot.
  • تحوّل bool() القيمة إلى حكم على حقيقتها المنطقية؛ فالصفر والنص الفارغ يعطيان False.
  • None تعني عدم وجود قيمة، ونوعها NoneType؛ افحصها باستخدام is None.
  • لا تخلط بين None وFalse و0؛ تشابه نتيجة bool() لا يعني تشابه المعنى أو النوع.

03أسئلة المقابلات

ما المقصود بـ Boolean Values، وما الفرق بين True وFalse؟ أساسي

هما القيمتان الوحيدتان من النوع bool، وتستخدمان لتمثيل نتيجة منطقية مثل تحقق شرط أو عدم تحققه. يجب كتابتهما بالصياغة الدقيقة True وFalse، فهما ليستا نصين.

ما الذي تمثله None، وكيف نتحقق من وجودها؟ أساسي

تمثل None غياب قيمة أو عدم تحديدها بعد، ونوعها NoneType. نتحقق منها عادةً باستخدام value is None، ونستخدم is not None للتحقق من أن القيمة موجودة.

ما الفرق بين Boolean Expression والدالة bool()؟ متوسط

التعبير المنطقي مثل customer_age >= 18 يبني نتيجة من مقارنة أو شروط. أما bool(value) فتحوّل قيمة موجودة إلى True أو False بحسب حقيقتها المنطقية، مثل كون النص فارغًا أو غير فارغ.

هل None وFalse و0 قيم متكافئة؟ متوسط

لا؛ None تعني غياب القيمة، وFalse إجابة منطقية سلبية، و0 عدد. تعطي القيم الثلاث False عند تمريرها إلى bool()، لكن None == False وNone == 0 نتيجتهما False.

ما ناتج bool("False")؟ ولماذا يُعد هذا سؤالًا خادعًا؟ سؤال فخ

الناتج هو True، لأن "False" نص غير فارغ. الدالة bool() تفحص حقيقة القيمة المنطقية لا معنى الكلمة المكتوبة داخل النص.

    نخزن حالتي الدفع والعنوان كقيم منطقية، ونمثل الملاحظة غير المدخلة بـ None، والرسوم كعدد. بعد ذلك نستخدم and وis not None والمقارنة مع الصفر.

  4. تفسير القرارات:

    احتفظ بـ None عندما تكون المعلومة غير مدخلة، وبـ False عندما توجد إجابة سلبية مؤكدة، وبـ 0 عندما تكون القيمة العددية صفرًا. هذا يمنع دمج حالات مختلفة في معنى واحد.

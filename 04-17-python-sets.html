01الشرح

Create Sets وAccess Set Items: الإنشاء والوصول

الـ set مجموعة غير مرتبة من عناصر فريدة. نحتاجها لإزالة التكرار، وللتحقق السريع من وجود عنصر عبر in، وللمقارنة بين مجموعات البيانات. ننشئها بالأقواس {} أو بالدالة set() على أي iterable، وأي تكرار يُحذف تلقائيًا.

لا يوجد index في الـ set، لذلك الوصول إلى العناصر يعني: اختبار الانتماء بـ in، أو المرور عليها بحلقة for، أو استخراج عنصر بـ pop() كما سنرى.

قيدان مهمان: {} وحدها تنشئ dict (نوع سنتعلمه لاحقًا) وليس set، فالمجموعة الفارغة تُنشأ بـ set() فقط. وعناصر الـ set يجب أن تكون hashable، أي عمليًا immutable؛ فلا يصح وضع list داخل set، لكن يصح tuple.

Add Set Items وRemove Set Items: الإضافة والحذف

الـ set قابلة للتعديل. add() تضيف عنصرًا واحدًا (وإن كان موجودًا لا يحدث شيء)، وupdate() تضيف عناصر من iterable واحد أو أكثر. في الحذف: remove() ترفع KeyError إن غاب العنصر، وdiscard() تتجاهل الغياب بصمت، وpop() تحذف عنصرًا اعتباطيًا وتعيده، وclear() تفرغ المجموعة، وdel name تحذف المتغير نفسه.

متى نستخدم ماذا؟ اختر remove() عندما يكون غياب العنصر خطأ منطقيًا تريد اكتشافه، وdiscard() عندما لا يهمك. وتذكّر أن pop() على set فارغة ترفع KeyError، ولا يجوز افتراض أي عنصر بعينه سيُحذف.

Loop Sets وJoin Sets: التكرار والدمج

نمرّ على الـ set بحلقة for كالمعتاد، لكن الترتيب غير مضمون؛ فإن احتجت ترتيبًا ثابتًا استخدم sorted() (تعيد list). أما الدمج والمقارنة فتتم بعمليات المجموعات: union() أو | للاتحاد، intersection() أو & للتقاطع، difference() أو - للفرق، symmetric_difference() أو ^ للعناصر الموجودة في إحدى المجموعتين فقط.

الفرق بين الشكلين: الـ operators تتطلب set على الجانبين، بينما الـ methods تقبل أي iterable مثل list. وunion() وأخواتها تُنتج set جديدة ولا تعدّل الأصلية، أما update() فتعدّلها في مكانها.

Frozenset: المجموعة الثابتة

الـ frozenset نسخة immutable من set: لا تحتوي add() ولا remove()، لكنها hashable. وهذا يعني أنها تصلح عنصرًا داخل set أخرى، وتصلح لتثبيت قيم لا يجب أن تتغير مثل مجموعة صلاحيات ثابتة. العمليات عليها (| و& وغيرهما) تعيد كائنًا جديدًا من نوع المعامل الأيسر.

Set Methods: أهم الدوال

إلى جانب ما سبق، هناك دوال للاختبار: issubset() (مثل <=)، وissuperset() (مثل >=)، وisdisjoint() للتأكد من عدم وجود عناصر مشتركة. وcopy() تنشئ نسخة مستقلة قبل التعديل. وهناك نسخ "في المكان" من العمليات: difference_update() وintersection_update() وsymmetric_difference_update() تعدّل الـ set نفسها بدل إنشاء جديدة.

02الملخص

  • الـ set مجموعة غير مرتبة من عناصر فريدة؛ تُنشأ بـ {} أو set(iterable)، والمجموعة الفارغة تُنشأ بـ set() فقط.
  • لا يوجد index؛ نصل إلى العناصر بـ in أو بحلقة for، ولا نعتمد على ترتيب المرور (نستخدم sorted() عند الحاجة).
  • العناصر يجب أن تكون hashable: يصح tuple وstr والأرقام، ولا يصح list.
  • الإضافة بـ add() وupdate()؛ والحذف بـ remove() (خطأ إن غاب) وdiscard() (بصمت) وpop() (عنصر اعتباطي) وclear().
  • الدمج والمقارنة: | و& و- و^ أو ما يقابلها من methods التي تقبل أي iterable، وصيغ *_update تعدّل في المكان.
  • الـ frozenset نسخة immutable وhashable تصلح عنصرًا داخل set؛ ودوال الاختبار: issubset() وissuperset() وisdisjoint().

03أسئلة المقابلات

ما الفرق الأساسي بين list وset؟ ومتى نفضّل الثانية؟ أساسي

الـ list مرتبة وتسمح بالتكرار وبالوصول بالـ index، أما الـ set فلا تضمن ترتيبًا ولا تقبل التكرار ولا تدعم الـ index. نفضّل set عندما نحتاج إزالة التكرار، أو اختبار انتماء سريعًا بـ in (يعتمد على hash بدل الفحص عنصرًا عنصرًا)، أو عمليات الاتحاد والتقاطع والفرق.

كيف تنشئ set فارغة؟ ولماذا لا تصلح {}؟ أساسي

نستخدم set(). أما {} فتُنشئ dict فارغًا لأن هذه الصيغة محجوزة له تاريخيًا. الأقواس تُنتج set فقط إذا احتوت عناصر مثل {1, 2}.

ما الفرق بين remove() وdiscard() وpop()؟ متوسط

remove(x) تحذف العنصر وترفع KeyError إن لم يوجد، فنستخدمها حين يكون غيابه خطأ. discard(x) تحذفه إن وجد وتتجاهل الغياب. أما pop() فلا تأخذ وسيطًا: تحذف عنصرًا اعتباطيًا وتعيده، وترفع KeyError إن كانت المجموعة فارغة.

لماذا لا يمكن وضع list داخل set؟ وما البدائل؟ متوسط

لأن عناصر الـ set يجب أن تكون hashable بقيمة hash ثابتة، والـ list قابلة للتعديل فلا تحقق ذلك (TypeError: unhashable type). البديل لتخزين تسلسل هو tuple، ولتخزين مجموعة داخل مجموعة هو frozenset.

ماذا تعيد len({1, True, 1.0})؟ ولماذا؟ فخ

تعيد 1. القيم 1 وTrue و1.0 متساوية (==) ولها نفس الـ hash، فتعدّها الـ set عنصرًا واحدًا، ويبقى أول عنصر أُدخل.

متابعة: ماذا يطبع print({True, 1})؟ يطبع {True} لأن True أُدخل أولًا.

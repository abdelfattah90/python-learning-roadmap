01الشرح

if وelif وelse: اختيار المسار المناسب

نحتاج الشروط عندما يجب أن يختلف سلوك البرنامج حسب قيمة أو حالة، بدل تنفيذ التعليمات نفسها دائمًا. تفحص if شرطًا؛ فإذا كانت نتيجته True نُفّذ جسمها، وإذا كانت False انتقل التنفيذ إلى الفرع التالي إن وُجد.

تضيف elif شرطًا بديلًا يُفحص فقط إذا لم يتحقق ما قبله، ويمكن كتابة أكثر من فرع منها. أما else فتلتقط كل الحالات المتبقية دون شرط خاص. يُنفّذ فرع واحد فقط من سلسلة if/elif/else، لذلك رتّب الشروط من الأكثر تحديدًا إلى الأعم. انتبه إلى النقطتين : والمسافة البادئة؛ فهما جزء من بناء الجملة.

الشرط الذي يختبر الحد الأعلى أولًا يمنع تصنيف الطلب الذي يحقق أكثر من حد في فئة أقل.

Shorthand If: شرط في سطر واحد

يمكن اختصار if البسيط إلى تعبير شرطي في سطر واحد عندما يكون القرار قصيرًا وواضحًا. الصيغة هي value_if_true if condition else value_if_false، ويمكن استخدامها لإسناد قيمة أو لطباعة نتيجة. لا تخلط بينها وبين سلسلة if/elif/else متعددة الأسطر؛ عند تعدد الفروع أو تعقّدها تكون الصيغة العادية أوضح.

Logical Operators: تركيب أكثر من شرط

تسمح العوامل المنطقية بدمج الشروط في قرار واحد: and تكون نتيجتها صحيحة عندما يكون الشرطان صحيحين، وor عندما يكون أحدهما على الأقل صحيحًا، وnot تعكس النتيجة. استخدمها مثلًا للتحقق من أهلية طلب أو صلاحية إدخال. تُقيّم Python التعبيرات من اليسار إلى اليمين مع short-circuit: قد لا تقيّم الطرف الثاني إذا حُسمت النتيجة من الأول.

الأقواس تجعل المقصود واضحًا عند مزج and وor، ولا تعتمد على تخمين أولوية العمليات. تذكّر أن الشروط قد تستخدم المقارنات التي تعلمتها سابقًا، مثل >= و==.

Nested If وpass Statement: التفرّع داخل التفرّع والجسم المؤقت

يسمى وضع if داخل جسم if آخر Nested If. يفيد عندما لا يكون فحص الشرط الداخلي منطقيًا إلا بعد نجاح الشرط الخارجي، مثل فحص صلاحية الحساب أولًا ثم مستوى الصلاحية. حافظ على المسافات البادئة بدقة؛ فالخطأ الشائع هو وضع الفرع في المستوى الخاطئ، كما أن كثرة التداخل تجعل القراءة أصعب، ويمكن غالبًا تبسيطها بشروط منطقية.

أما pass فهي تعليمة لا تنفذ أي عمل؛ تُستخدم مؤقتًا عندما يتطلب تركيب Python جسمًا ولا تريد كتابة التنفيذ بعد. إنها ليست بديلًا عن شرط، ولا تتخطى بقية البرنامج، بل تسمح ببقاء البنية صحيحة حتى تُكملها.

02الملخص

  • تُنفّذ if جسمها عندما يكون الشرط True، وتُستخدم elif لفحص بدائل متتابعة.
  • تلتقط else الحالات التي لم يلتقطها أي شرط سابق؛ ويُنفّذ فرع واحد من السلسلة.
  • اختصر القرار البسيط باستخدام Shorthand If، وتجنبه إذا أضعف وضوح الكود.
  • ادمج الشروط بواسطة and وor وnot، واستخدم الأقواس لتوضيح المنطق.
  • استخدم Nested If عندما يعتمد فحص داخلي على نجاح فحص خارجي، وتجنب التداخل الزائد.
  • تُبقي pass جسم الكتلة صالحًا دون تنفيذ أي عمل؛ استبدلها بالتنفيذ الحقيقي لاحقًا.

03أسئلة المقابلات

ما الفرق بين elif وif مستقلة؟أساسي

تُفحص elif فقط إذا فشلت الشروط السابقة في السلسلة نفسها، وتضمن السلسلة تنفيذ فرع واحد كحد أقصى. أما جملة if مستقلة فتُفحص دائمًا، وقد تُنفّذ عدة كتل مستقلة في التشغيل نفسه.

متى نستخدم else، وهل يمكن أن تحتوي شرطًا؟أساسي

تُستخدم else للحالة المتبقية إذا لم يتحقق if أو أي elif سابق. لا تكتب شرطًا معها؛ إذا احتجت فحصًا إضافيًا فاستخدم elif.

ما الذي يميز and عن or، وما المقصود بـ short-circuit؟متوسط

تتطلب and تحقق جميع الشروط، بينما يكفي تحقق شرط واحد مع or. في short-circuit تتوقف Python عن تقييم بقية التعبير عندما تكون النتيجة قد حُسمت بالفعل.

متى يكون Nested If مناسبًا، وما عيبه المحتمل؟متوسط

يكون مناسبًا عندما يعتمد قرار داخلي على نجاح قرار خارجي، مثل التحقق من الحساب قبل صلاحياته. كثرة المستويات تزيد صعوبة القراءة، لذا افحص إمكانية دمج الشروط المنطقية دون تغيير المعنى.

هل pass تعني تجاوز الشرط أو إيقاف البرنامج؟سؤال فخ

لا؛ pass تعليمة فارغة لا تفعل شيئًا، ويستمر التنفيذ بعد الكتلة كالمعتاد. لا تتجاوز الشرط ولا توقف البرنامج، وإنما توفر جسمًا صحيحًا نحويًا أثناء تأجيل كتابة التنفيذ.

04المسألة العملية

المطلوب: تحديد أهلية خصم متجر

اكتب برنامجًا يحدد رسالة الخصم لطلب متجر تجريبي. الطلب مؤهل لخصم العضوية إذا كان العميل عضوًا وكان إجمالي الطلب 300 أو أكثر، أو لخصم خاص إذا بلغ الإجمالي 500 أو أكثر دون ذلك؛ وما عدا ذلك لا يحصل على خصم. إذا كان الإجمالي صفرًا أو أقل، اطبع رسالة رفض بدل تصنيف الخصم.

  1. فهم المطلوب: نحتاج رفض الإجمالي غير الموجب، ثم تحديد نوع الخصم للحالات الصحيحة.
  2. خطة الحل: نتحقق أولًا من صحة الإجمالي، ثم نستخدم if/elif/else بترتيب الشروط المناسب.
  3. الكود الكامل:
  4. تفسير القرارات: فحص الإجمالي أولًا يمنع منح خصم لطلب غير صالح. يأتي شرط العضوية قبل الخصم العام لأن العضو الذي طلبه 520 يحقق الشرطين، ويجب تصنيفه ضمن خصم العضوية.
  5. اختبار سريع: عند order_total = 0 تظهر رسالة الرفض؛ وعند order_total = 350 وis_member = False تظهر رسالة عدم وجود خصم.
  6. تحسين أو بديل: عند إضافة أنواع خصومات كثيرة، اجعل الشروط مرتبة بوضوح واكتب اختبارًا لكل حد فاصل؛ لا تختصر سلسلة طويلة في Shorthand If.

01الشرح

إنشاء المصفوفات — Create Arrays

Python لا تحتوي نوع array داخل اللغة نفسها؛ ما يسميه الناس «array» غالبًا هو list. المصفوفة الحقيقية تأتي من module اسمه array في الـ standard library. نحتاجها عندما نخزّن عددًا كبيرًا من القيم الرقمية من نوع واحد (قراءات حساسات مثلًا)، لأنها تحفظ القيم نفسها بنوع C ثابت بدل مراجع لكائنات مختلفة، فتكون أكثر اقتصادًا في الذاكرة وترفض الأنواع الخاطئة.

الصيغة: array(typecode, initializer). الـ typecode حرف واحد يحدد نوع كل العناصر: "i" عدد صحيح signed، و"d" عدد عشري double، و"b" عدد صحيح صغير (1 byte). الـ initializer يمكن أن يكون list أو range أو أي iterable.

تنبيه: كل عنصر يجب أن يطابق نوع الـ typecode؛ وإدخال قيمة خارج مدى النوع (مثل 200 في "b") يرفع OverflowError.

الوصول إلى العناصر — Access Array Items

نقرأ العناصر بالـ index كما في الـ list: العد يبدأ من 0، والـ index السالب يعدّ من النهاية. الـ slicing يعيد array جديدة من النوع نفسه وليس list. ونستخدم len() لمعرفة العدد، وحلقة for للمرور على القيم.

تنبيه: أي index خارج المدى يرفع IndexError، بينما الـ slice الخارج عن المدى لا يرفع خطأً بل يعيد ما هو متاح فقط.

إضافة العناصر وحذفها — Add & Remove Array Items

الإضافة: append(x) تضيف عنصرًا في النهاية، وinsert(i, x) تضيفه في موضع محدد وتزيح ما بعده، وextend(iterable) تضيف عدة عناصر. إذا مرّرت array أخرى إلى extend فيجب أن يتطابق الـ typecode.

الحذف: remove(x) تحذف أول عنصر قيمته x، وpop(i) تحذف حسب الـ index وتعيد القيمة (الافتراضي هو العنصر الأخير)، وdel arr[i] تحذف دون إرجاع وتقبل slice أيضًا.

تنبيه: remove(x) ترفع ValueError إذا لم تجد القيمة، فاستخدم if x in arr قبلها عند عدم اليقين.

تحديث العناصر — Update Array Items

التحديث يتم بالإسناد: arr[i] = value تستبدل عنصرًا واحدًا، وarr[a:b] = other_array تستبدل شريحة كاملة. القيد المهم أن القيمة المسندة يجب أن تطابق الـ typecode، وأن الشريحة لا تقبل list عادية بل array من النوع نفسه.

المصفوفات مقابل القوائم — Arrays vs. Lists

الـ list مرنة: تقبل أنواعًا مختلفة وتحتوي قوائم أخرى، ولها methods غنية مثل sort(). أما الـ array فمقيّدة بنوع واحد، ومضغوطة، ولا تملك sort(). القاعدة العملية: ابدأ بـ list دائمًا، واختر array فقط عند وجود كمية كبيرة من أرقام متجانسة أو حاجة للتعامل مع بيانات binary. وللتحويل بين النوعين نستخدم tolist() وarray(typecode, my_list).

02الملخص

  • Python لا تملك array مدمجة في اللغة؛ المصفوفة الحقيقية تأتي من module array، وما نسميه غالبًا array هو list.
  • ننشئ المصفوفة بـ array(typecode, initializer)، وكل عناصرها من نوع واحد يحدده الـ typecode مثل "i" و"d".
  • القراءة بالـ index والـ slicing تعمل كما في list، لكن الـ slice يعيد array من النوع نفسه، والـ index الخاطئ يرفع IndexError.
  • الإضافة بـ append وinsert وextend، والحذف بـ remove (حسب القيمة) وpop وdel (حسب الموضع).
  • التحديث بالإسناد يتطلب مطابقة النوع، وإسناد شريحة يتطلب array من نفس الـ typecode وليس list.
  • اختر list افتراضيًا، واستخدم array لبيانات رقمية متجانسة وكبيرة؛ وتذكّر أن array لا تملك sort() ولا تقبل أنواعًا مختلطة.

03أسئلة المقابلات

هل لدى Python نوع array مدمج؟ أساسي

ليس كنوع في اللغة نفسها؛ ما يُستخدم عادةً بدلًا منه هو list. المصفوفة المقيّدة بنوع تأتي من module array في الـ standard library، وتُنشأ بـ array(typecode, initializer).

انتبه للفرق: import array تستورد الـ module (فتكتب array.array(...))، أما from array import array فتستورد الـ class مباشرة.

ما وظيفة الـ typecode، وماذا يحدث عند إدخال قيمة من نوع مختلف؟ أساسي

الـ typecode حرف يحدد نوع كل عناصر المصفوفة (مثل "i" لعدد صحيح و"d" لعدد عشري). إدخال قيمة من نوع غير مناسب يرفع TypeError، وقيمة خارج مدى النوع ترفع OverflowError.

ما الفرق بين remove وpop وdel في array؟ متوسط

remove(x) تحذف أول عنصر بقيمة محددة وترفع ValueError إذا لم توجد. pop(i) تحذف حسب الـ index وتعيد القيمة المحذوفة. del arr[i] تحذف حسب الـ index (أو slice) دون إرجاع شيء.

متى تختار array بدل list؟ متوسط

عندما تكون البيانات كثيرة وأرقامًا من نوع واحد، فتستفيد من التخزين المضغوط ومن رفض الأنواع الخاطئة تلقائيًا. وفي بقية الحالات (أنواع مختلطة، قوائم متداخلة، حاجة إلى sort()) تكون list هي الخيار الأنسب.

ماذا يحدث عند تنفيذ numbers[1:3] = [7, 8] على array من النوع "i"؟ فخ

يرفع TypeError، لأن إسناد شريحة في array يتطلب array من نفس الـ typecode وليس list. الصيغة الصحيحة: numbers[1:3] = array("i", [7, 8]).

04المسألة العملية

محطة أرصاد تسجّل درجات الحرارة بعُشر الدرجة (القيمة 215 تعني 21.5 درجة) في array من النوع "i". القيمة -999 تعني أن الحساس معطّل. المطلوب: أنشئ المصفوفة من [215, 230, -999, 198, 224]، واحذف القراءة المعطّلة بأمان، وأضف قراءة جديدة 241، وصحّح أول قراءة إلى 218، وأدخل 205 في الموضع 2، ثم اطبع المصفوفة والمتوسط وأكبر قيمة.

  1. فهم المطلوب

    المدخل array من أعداد صحيحة فيها قيمة معطّلة. المطلوب أربع عمليات تعديل (حذف، إضافة، تحديث، إدخال) ثم حساب المتوسط وأكبر قيمة.

  2. خطة الحل

    ننشئ المصفوفة، ثم نتحقق من وجود -999 ونحذفها، ثم append للقراءة الجديدة، ثم الإسناد بالـ index للتصحيح، ثم insert في الموضع المطلوب، وأخيرًا نحسب المتوسط وأكبر قيمة.

  3. الكود الكامل

  4. تفسير القرارات

    اخترنا "i" لأن التخزين بعُشر الدرجة يجعل كل القيم أعدادًا صحيحة. فحص in قبل remove يمنع ValueError. وتعمل sum وmax على الـ array مباشرة لأنها iterable، ونقسم على len لحساب المتوسط.

  5. اختبار سريع

    تأكد أن المخرجات تطابق ما فوق. ثم جرّب إزالة -999 من القراءات الأولية فلا يجب أن يحدث خطأ، وجرّب readings.append(24.1) لترى TypeError يؤكد أن المصفوفة مقيّدة بنوعها.

  6. تحسين أو بديل

    remove تحذف أول قراءة معطّلة فقط. للتنظيف الكامل أنشئ array("i") فارغة، ومرّ على القراءات الخام بحلقة for، وأضف بـ append القيم التي لا تساوي -999 فقط. وإذا احتجت لاحقًا إلى ترتيب القراءات فحوّلها بـ tolist() ثم استخدم sort().

01الشرح

Keyword Arguments — تسمية الوسيط عند الاستدعاء

عندما تملك الدالة ثلاثة parameters أو أكثر، يصبح استدعاء مثل create_order("keyboard", 2, True) غامضًا: عليك تذكّر الترتيب، ولا يوضح الاستدعاء ماذا تعني True. مع keyword arguments تكتب name=value فيصبح الاستدعاء مقروءًا ولا يهم ترتيب الوسائط.

يمكنك المزج بين النوعين بشرط أن تأتي الـ positional أولًا ثم الـ keyword. أشهر الأخطاء: وضع positional بعد keyword يسبب SyntaxError، وتمرير الـ parameter نفسه مرتين أو استخدام اسم غير موجود يسبب TypeError.

Default Parameter Values — القيم الافتراضية

تجعل الـ parameter اختياريًا بكتابة name=value في تعريف الدالة؛ فإذا لم يمرره المستدعي تُستخدم القيمة الافتراضية. هذا مفيد للإعدادات الشائعة مثل port و timeout، ويعمل جيدًا مع الـ keyword arguments لتغيير خيار واحد وترك الباقي. القاعدة: الـ parameters الإلزامية أولًا ثم التي لها قيمة افتراضية، وإلا حصلت على SyntaxError.

الفخ المهم: القيمة الافتراضية تُحسب مرة واحدة عند تنفيذ def، لا عند كل استدعاء. لذلك إذا كانت list أو dict فسيتشاركها كل استدعاء ويتراكم فيها التعديل. الحل المعتاد: اجعل الافتراضي None وأنشئ الكائن الجديد داخل الدالة.

Variable-length Arguments و *args — عدد غير محدد من الوسائط

أحيانًا لا تعرف مسبقًا كم قيمة سيمرر المستدعي: مجموع أسعار، متوسط درجات، رسائل سجل. بدل تحديد parameters ثابتة، تضع *name في التعريف فتجمع Python كل الوسائط الـ positional الزائدة داخل tuple. الاسم args مجرد اتفاق شائع، والمهم هو النجمة. وإذا لم يُمرَّر شيء يكون الـ tuple فارغًا، ولهذا فحصنا الحالة الفارغة في المثال.

في الاستدعاء تعمل النجمة بالعكس: average(*grades) تفكّ الـ list إلى وسائط منفصلة. تنبيه: أي parameter يأتي بعد *args في التعريف لا يمكن تمريره إلا بالاسم.

**kwargs — خيارات مسمّاة غير محددة

هي نظير *args للوسائط المسمّاة: **context تجمع أي keyword arguments غير معرّفة كـ parameters داخل dict (الاسم هو المفتاح والقيمة هي القيمة). تناسب الدوال التي تقبل بيانات إضافية متغيرة، أو التي تمرر خياراتها إلى دالة أخرى. وفي الاستدعاء تفكّ **data الـ dict إلى keyword arguments. عند الجمع بينها وبين غيرها الترتيب ثابت: parameters عادية، ثم *args، ثم **kwargs.

قيد مهم: **kwargs يقبل أي اسم بصمت، فخطأ إملائي في اسم الوسيط لن يُكتشف. استخدمه فقط عندما تكون المفاتيح مفتوحة فعلًا، وإلا فالأفضل parameters صريحة.

02الملخص

  • Keyword arguments: تُكتب name=value عند الاستدعاء، ولا يهم ترتيبها، لكن الـ positional تأتي أولًا.
  • Default values: تُكتب في def وتجعل الـ parameter اختياريًا، ويجب أن تأتي بعد الـ parameters الإلزامية.
  • لا تستخدم list أو dict كقيمة افتراضية؛ لأنها تُحسب مرة واحدة وتُشارَك. استخدم None وأنشئ الكائن داخل الدالة.
  • *args تجمع الـ positional الزائدة في tuple، وقد يكون فارغًا.
  • **kwargs تجمع الـ keyword الزائدة في dict، وتُخفي الأخطاء الإملائية في الأسماء.
  • الترتيب في التعريف: عادية ثم *args ثم **kwargs؛ وفي الاستدعاء تفكّ * و ** التسلسل والـ dict إلى وسائط.

03أسئلة المقابلات

ما الفرق بين positional و keyword arguments، ومتى تفضّل الثاني؟ أساسي

الـ positional تُربط بالـ parameters حسب موضعها، والـ keyword تُربط بالاسم. أفضّل الثاني عندما تكثر الـ parameters أو تكون القيم مثل True و None غير واضحة المعنى، فيصبح الاستدعاء مقروءًا ويمكنني تخطي الاختياري منها.

متابعة: ماذا يحدث لو مررت نفس الـ parameter مرتين، مرة بالموضع ومرة بالاسم؟ يحدث TypeError لأنه حصل على أكثر من قيمة.

ما الفرق بين *args و **kwargs؟ أساسي

*args تجمع الوسائط الـ positional الزائدة في tuple، و **kwargs تجمع الـ keyword الزائدة في dict مفاتيحه أسماء الوسائط. كلاهما يُستخدم عندما لا نعرف عدد الوسائط مسبقًا.

متابعة: هل الاسمان args و kwargs إلزاميان؟ لا، هما اتفاق فقط، والنجمة هي التي تحدد السلوك.

لماذا يرفض Python التعريف def f(a=1, b)؟ وما الترتيب الصحيح؟ متوسط

لأن parameter بلا قيمة افتراضية بعد آخر لها قيمة يجعل الربط الموضعي غامضًا، فتُرفض الصياغة بـ SyntaxError. الترتيب الصحيح: الإلزامية، ثم التي لها default، ثم *args، ثم **kwargs، مثل def f(a, b=1, *args, **kwargs).

كيف تمرر كل الوسائط التي استلمتها إلى دالة أخرى دون معرفتها مسبقًا؟ متوسط

أعرّف دالة وسيطة بـ def wrapper(*args, **kwargs) لتلتقط كل شيء، ثم أستدعي الهدف بـ target(*args, **kwargs) فتُفكّ الوسائط كما وصلت. هذا النمط شائع في الدوال التي تغلّف غيرها دون تغيير توقيعها.

دالة def add_item(item, items=[]) تضيف العنصر وتعيد القائمة. ماذا تُرجِع add_item("a") ثم add_item("b")؟ فخ

الأولى تعيد ['a'] والثانية تعيد ['a', 'b']. السبب أن القائمة الافتراضية أُنشئت مرة واحدة عند تنفيذ def وتتشاركها كل الاستدعاءات التي لا تمرر items.

الحل: items=None ثم if items is None: items = [] داخل الدالة.

خطة تعلّم Python

خريطة طريق لتعلّم Python مقسَّمة إلى دروس مرتبة، بعد تجاوز مرحلة المقدمة وإعداد البيئة. كل درس بحجم محادثة واحدة، ومعه Prompt جاهز يبني لك صفحة HTML تشرح الموضوع وتلخّصه ثم تختبرك بأسئلة مقابلات ومسألة عملية.

13 مرحلة تعليمية 63 درسًا
  1. 1

    محادثة جديدة لكل درس

    ابدأ محادثة مستقلة لكل درس لتسهيل تنظيم الشرح والرجوع إلى ملفاته، ويمكنك استخدام أي مساعد ذكاء اصطناعي يدعم المرفقات وإنشاء الملفات.

  2. 2

    انسخ Prompt الدرس

    اضغط «نسخ Prompt» بجانب الدرس، ثم الصقه في المساعد الذي تستخدمه وأرفق معه templet.html. احتفظ بمجلد assets كما هو بجانب ملفات الدروس ليعمل التنسيق.

  3. 3

    تابع بكلمة واحدة

    نزّل ملف الشرح والملخص، ثم اكتب الجزء الثاني في المحادثة نفسها لإضافة الأسئلة والمسألة. إذا انقطعت المحادثة، افتح محادثة جديدة، وأرفق آخر ملف HTML محفوظ، وانسخ Prompt الدرس نفسه، ثم اكتب استكمال.

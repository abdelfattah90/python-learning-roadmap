01الشرح

Constructor و Object Initialization

إذا أنشأت كائنًا من class فارغ فستضطر إلى إضافة خصائصه يدويًا سطرًا بعد سطر، وقد ينسى أحدهم خاصية فيظهر AttributeError لاحقًا. الحل هو الـ Constructor: دالة اسمها __init__ تستدعيها Python تلقائيًا فور إنشاء الكائن، فتتم تهيئة الكائن (Object Initialization) في مكان واحد ويولد كل كائن بالبنية نفسها.

لا تستدعِ __init__ بنفسك، ولا تجعلها ترجع قيمة؛ وظيفتها التهيئة فقط.

Constructor Parameters

الوسائط التي تكتبها عند الإنشاء (Product("Laptop", 1200)) تصل إلى معاملات __init__ بعد self مباشرة، وتنطبق عليها قواعد الدوال التي تعرفها: positional وkeyword وقيم افتراضية. اجعل البيانات الأساسية إلزامية حتى لا يُنشأ كائن ناقص، واستخدم القيم الافتراضية للخيارات، ويمكنك تنظيف المدخلات قبل حفظها.

الخطأ الشائع: نسيان معامل إلزامي عند الإنشاء يعطي TypeError قبل أن يُنشأ الكائن أصلًا.

self و Instance Attributes

داخل __init__ نحتاج أن نقول «خزّن هذه البيانات في هذا الكائن بالذات». هنا يأتي self: مرجع إلى الكائن الحالي، تمرره Python تلقائيًا كأول معامل. وما نخزنه بالصيغة self.name = name هو Instance Attribute: خاصية تخص هذا الكائن وحده، ولكل كائن نسخته المستقلة.

الاسم self تقليد وليس keyword، فلا تغيّره. والخطأ الأهم: كتابة score = 0 بدل self.score = 0 تنشئ متغيرًا محليًا يزول بانتهاء الدالة.

Instance Methods

الدالة المعرّفة داخل class وأول معاملاتها self هي Instance Method؛ بواسطة self تقرأ حالة الكائن وتعدّلها. عند استدعاء account.deposit(50) تمرّر Python الكائن account كـ self تلقائيًا، وهذا مكافئ لـ BankAccount.deposit(account, 25).

نسيان self في تعريف الدالة يعطي TypeError، ونسيان self. عند قراءة خاصية داخلها يعطي NameError.

02الملخص

  • __init__ هي الـ Constructor: تستدعيها Python تلقائيًا بعد إنشاء الكائن لتهيئته، ولا ترجع قيمة.
  • تهيئة الكائن في مكان واحد تضمن أن كل كائن يبدأ بنفس الخصائص الأساسية.
  • الـ Constructor Parameters تأتي بعد self وتدعم positional وkeyword والقيم الافتراضية؛ والمعامل الإلزامي بلا قيمة افتراضية.
  • self مرجع إلى الكائن الحالي تمرره Python تلقائيًا، واسمه تقليد وليس keyword.
  • self.x = x ينشئ Instance Attribute مستقلة لكل كائن، أما x = 0 بلا self فمتغير محلي يزول.
  • الـ Instance Method تأخذ self أولًا لتقرأ الحالة وتعدّلها، وobj.method(a) تساوي Class.method(obj, a).

03أسئلة المقابلات

ما وظيفة __init__ ومتى تُستدعى؟أساسي

هي الـ Constructor في Python (تقنيًا هي initializer تهيّئ كائنًا أُنشئ بالفعل). تستدعيها Python تلقائيًا عند كتابة ClassName(...) وتمرّر لها الوسائط لتخزنها في خصائص الكائن.

متابعة: هل نستدعيها يدويًا؟ لا، فاستدعاؤها يعيد تهيئة كائن موجود ولا ينشئ كائنًا جديدًا.

ما هو self، وهل هو keyword؟أساسي

هو مرجع إلى الكائن الحالي، وأول معامل في كل Instance Method، وتمرره Python تلقائيًا. ليس keyword ويمكن تسميته بأي اسم، لكن الالتزام بـ self هو المعيار الذي يتوقعه كل مبرمج Python.

كيف تعمل account.deposit(50) مع أن الدالة معرّفة بمعاملين؟متوسط

تحوّلها Python إلى BankAccount.deposit(account, 50)، فيصبح account هو self و50 هو amount. لذلك نسيان self في التعريف يعطي TypeError لأن عدد الوسائط يزيد واحدًا.

ما الفرق بين self.score = 0 وscore = 0 داخل __init__؟متوسط

الأولى تنشئ Instance Attribute تبقى مع الكائن وتصل إليها بقية الـ methods. الثانية متغير محلي يزول عند نهاية __init__، فتحصل على AttributeError عند قراءة obj.score لاحقًا.

ما المشكلة في def __init__(self, tags=[])؟فخ

القيمة الافتراضية تُنشأ مرة واحدة عند تعريف الدالة، فكل الكائنات التي لا تمرّر tags تشارك القائمة نفسها، وأي تعديل في كائن يظهر في الباقي. الحل: tags=None ثم self.tags = [] if tags is None else tags.

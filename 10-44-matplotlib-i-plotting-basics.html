01الشرح

Introduction و Get Started: ما Matplotlib وكيف نبدأ

Matplotlib هي المكتبة الأساسية في Python لرسم البيانات (static, animated, interactive). نحتاجها لأن الأرقام الخام داخل arrays يصعب قراءة نمطها بالعين: الاتجاه العام (trend) والقيم الشاذة (outliers) تظهر في ثوانٍ عندما تُرسم. وهي مبنية فوق NumPy وتتعامل مع arrays مباشرة، ولذلك جاءت بعد دروس NumPy.

نثبتها داخل virtual environment بالأمر python -m pip install matplotlib كما تعلمنا في درس PIP & VirtualEnv، ثم نستورد وحدة pyplot بالاسم المستعار المتعارف عليه plt. للتأكد من نجاح التثبيت نقرأ matplotlib.__version__. الخطأ الشائع هنا هو ModuleNotFoundError: غالبًا لأن التثبيت تم في بيئة غير التي يعمل بها الكود.

Pyplot و Plotting: من القيم إلى الرسم

matplotlib.pyplot واجهة بسيطة تحتفظ بالرسم الحالي (current figure) وتعدّله دالة بعد أخرى، فلا تحتاج لإنشاء كائنات بنفسك في البداية. الدالة plt.plot(x, y) تأخذ قيم المحور الأفقي والرأسي وتوصل النقاط (x[i], y[i]) بخطوط مستقيمة بالترتيب، وplt.show() هي التي تعرض الرسم فعليًا في السكربت.

لرسم نقاط بلا خط نمرّر النص "o" كـ format string. وإذا مررنا وسيطًا واحدًا فقط تُعامل القيم على أنها y ويُولَّد x تلقائيًا كـ 0, 1, 2, .... القيد الأهم: يجب أن يتساوى طول x و y وإلا يحدث ValueError، كما أن ترتيب النقاط يحدد مسار الخط.

Markers: إبراز نقاط القياس

الخط وحده يخفي مواضع القياسات الفعلية، خصوصًا عندما تتباعد النقاط. لذلك نضيف marker لرسم علامة عند كل نقطة. أشهر الأشكال: "o" دائرة، "*" نجمة، "." نقطة، "x" و"X" علامة ×، "+" و"P" علامة +، "s" مربع، "D" و"d" معين، "p" خماسي، "h" و"H" سداسي، "v" و"^" و"<" و">" مثلثات.

للتحكم في المظهر: markersize (أو ms) للحجم، وmarkerfacecolor (mfc) للون الداخل، وmarkeredgecolor (mec) للون الحافة. وهناك صيغة مختصرة هي format string بالترتيب الثابت "marker|line|color" مثل "o:r". قيدها أنها تقبل ألوانًا بحرف واحد فقط (r g b c m y k w)؛ أما الأسماء والـ hex فتحتاج keyword color. لا تعرّف الخاصية بالطريقتين معًا لأن Matplotlib تحذّر وتُقدّم الـ keyword.

Line: نمط الخط ولونه وسمكه وتعدد الخطوط

نمط الخط linestyle (أو ls) يساعد على التمييز بين الخطوط حتى في الطباعة بالأبيض والأسود: "solid" أو "-"، "dotted" أو ":"، "dashed" أو "--"، "dashdot" أو "-.". اللون color (أو c) يقبل اسمًا مثل "hotpink" أو hex مثل "#4CAF50"، والسمك linewidth (أو lw) رقم بوحدة points.

لرسم عدة خطوط في صورة واحدة نستدعي plt.plot أكثر من مرة قبل plt.show()، أو نمرّر أزواج x و y في استدعاء واحد مثل plt.plot(x1, y1, x2, y2). وتنبّه: show() تُنهي الرسم الحالي، فأي plot بعدها يبدأ رسمًا جديدًا.

02الملخص

  • Matplotlib مكتبة رسم مبنية فوق NumPy؛ تُثبَّت بـ pip وتُستورد عادةً بالشكل import matplotlib.pyplot as plt.
  • plt.plot(x, y) ترسم خطًا بين النقاط بالترتيب، وplt.show() تعرض الرسم وتُنهي الرسم الحالي.
  • مع وسيط واحد plt.plot(y) يصبح x هو 0, 1, 2, ...؛ ويجب أن يتساوى طول x و y وإلا ValueError.
  • marker يرسم علامة عند كل نقطة، ويُضبط بـ markersize وmarkerfacecolor وmarkeredgecolor.
  • الـ format string "marker|line|color" مثل "o:r" مختصرة لكنها تقبل ألوان الحرف الواحد فقط.
  • linestyle وcolor وlinewidth تتحكم في الخط، وتعدد استدعاءات plot قبل show() يرسم عدة خطوط معًا.

03أسئلة المقابلات

ما الفرق بين matplotlib وmatplotlib.pyplot، ولماذا نكتب import matplotlib.pyplot as plt؟أساسي

matplotlib هي الحزمة الكبيرة، أما pyplot فوحدة داخلها تقدم واجهة سهلة (state-based) تدير الرسم الحالي تلقائيًا عبر دوال مثل plot وshow. الاسم المستعار plt اصطلاح متفق عليه لتقصير الكتابة وتوحيد الأكواد بين المطورين.

ماذا يحدث عند استدعاء plt.plot(y) بوسيط واحد؟أساسي

تُعامل القيم على أنها محور y، ويولّد Matplotlib محور x تلقائيًا بالقيم 0, 1, 2, ... حسب عدد العناصر. مفيد لرسم سلسلة قراءات سريعة، لكن إذا كانت لدى x قيم حقيقية (مثل الساعات) فيجب تمريرها صراحةً.

ما الفرق بين الـ format string مثل "o:r" والـ keyword arguments؟متوسط

كلاهما يضبط marker ونمط الخط واللون. الـ format string أقصر لكنها بترتيب ثابت وتقبل لونًا بحرف واحد فقط، بينما الـ keywords أوضح وتدعم hex وأسماء الألوان وmarkersize وغيرها. لا تعرّف الخاصية نفسها بالطريقتين: تظهر UserWarning ويُقدَّم الـ keyword.

كيف ترسم أكثر من خط في نفس الصورة؟ ومتى يبدأ رسم جديد؟متوسط

نستدعي plt.plot عدة مرات قبل plt.show()، أو نمرّر عدة أزواج (x1, y1, x2, y2) في استدعاء واحد، وتُلوَّن الخطوط تلقائيًا بألوان مختلفة. بعد show() يُعتبر الرسم منتهيًا، وأي plot لاحق يبدأ رسمًا جديدًا.

ما سبب الخطأ في plt.plot([1, 2, 3], [4, 5])؟فخ

لأن عدد قيم x (3) لا يساوي عدد قيم y (2)، فيرفع Matplotlib الخطأ ValueError: x and y must have same first dimension, but have shapes (3,) and (2,). كل نقطة تحتاج زوجًا كاملًا (x, y)، فلا يوجد تعويض تلقائي للقيم الناقصة.

تحقق مبكرًا بـ assert len(x) == len(y) عندما تأتي البيانات من مصادر متعددة.

04المسألة العملية

لديك زمن الاستجابة بالـ ms لخادمين خلال 7 أيام: الخادم الأساسي primary والاحتياطي backup. ارسمهما في صورة واحدة: الأساسي بخط أخضر سميك مع علامات دائرية، والاحتياطي بخط رمادي متقطع مع علامات مربعة. ثم علّم أبطأ يوم للخادم الأساسي بعلامة X حمراء كبيرة، واطبع رقم اليوم وزمن الاستجابة.

  1. فهم المطلوب

    المدخلات ثلاث arrays بطول 7، والمخرج رسم واحد فيه خطان بأنماط مختلفة ونقطة مميزة، مع سطر نصي يوضح أبطأ يوم.

  2. خطة الحل

    نجهّز البيانات ونتحقق من تساوي الأطوال، ثم نرسم الخطين بالـ keywords، ثم نحدد فهرس أكبر قيمة ونرسمها كنقطة مستقلة، وأخيرًا نطبع النتيجة ونستدعي show().

  3. الكود الكامل

  4. تفسير القرارات

    استخدمنا الـ keywords للخطين لأن الألوان "green" و"gray" أسماء كاملة لا تقبلها الـ format string، أما النقطة المنفردة فمناسبة لـ "rX" لأنها لون بحرف واحد. وجود assert يمنع ValueError غامضًا لاحقًا، وshow() جاءت أخيرًا لأنها تنهي الرسم الحالي.

  5. اختبار سريع

    الناتج المتوقع في الطرفية هو Slowest day: 4 (210 ms)، وفي الرسم يجب أن تظهر علامة X حمراء فوق اليوم الرابع. جرّب تغيير طول backup إلى 6 عناصر لترى فشل الـ assert.

  6. تحسين أو بديل

    يمكن اختصار الخطين بالـ format string: "go-" للأساسي و"s--" للاحتياطي، لكنها تفقد التحكم في السمك والرمادي. وعند تكرار الرسم لخوادم كثيرة، ضع البيانات في dict واستخدم for loop حول plt.plot.
